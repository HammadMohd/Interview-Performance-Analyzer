SECTION 3: FEATURE CATEGORIES
================================================================================

The 75 columns are organized into the following categories:

1. METADATA & IDENTITY (7 columns)
   - id, file_name, duration_label, question_id, question, user_no
   - Plus answer_score from target_features.csv

2. PERSONALITY TRAITS (6 columns)
   - openness, conscientiousness, extraversion, agreeableness, neuroticism
   - overall_personality (composite)

3. AUDIO FEATURES (19 columns)
   - Basic: Duration_Sec, Speech_Rate_WPM, Silence_Duration_Sec
   - Pitch/Energy: Mean_Pitch_Hz, Mean_Energy, Mean_ZCR
   - MFCC: MFCC_1 through MFCC_13 (spectral features)

4. TRANSCRIPT (1 column)
   - transcript (text with timestamps)

5. FACE & GAZE FEATURES (14 columns)
   - face_detected_ratio
   - Gaze: gaze_ratio_mean, gaze_deviation_mean, gaze_stability_std
   - Mouth: smile_score_mean/std, frown_score_mean/std
   - Eyes/Brows: eye_openness_mean/std, jaw_open_mean/std, 
                 brow_raise_mean/std, mouth_frown_mean/std

6. EMOTION FEATURES (7 columns)
   - emotion_happy_mean, emotion_sad_mean, emotion_angry_mean
   - emotion_surprise_mean, emotion_fear_mean, emotion_disgust_mean
   - emotion_neutral_mean

7. POSTURE FEATURES (11 columns)
   - Head/Shoulders: head_centering_score_mean, absolute_shoulder_slope_mean,
                     shoulder_slope_var, shoulder_width_mean/var,
                     nose_shoulder_dist_mean/var
   - Hands: hand_speed_mean, hand_to_face_touches, crossed_arms_score
   - Core: core_speed_mean, posture_shift_count

8. BEHAVIORAL SCORES (2 columns)
   - engagement_score, agitation_score

9. TARGET VARIABLES (6 columns)
   - interview_score, answer_score, speaking_skills
   - confidence_score, facial_expression, overall_performance

SECTION 6: DATA CHARACTERISTICS
================================================================================

1. MULTIMODAL NATURE
   The dataset combines four distinct data modalities:
   - Audio: Speech patterns, prosody, spectral features
   - Visual: Facial expressions, gaze tracking, emotions
   - Posture: Body language, gestures, movement
   - Text: Transcript content (for NLP analysis)

2. HIERARCHICAL STRUCTURE
   - Segments (rows) are nested within users
   - Each user answered multiple questions (1-17 segments)
   - This requires user-level splitting to avoid data leakage

3. STANDARDIZED SCORES
   - All personality traits are Z-scores (mean=0, std=1)
   - All target variables are Z-scores
   - Audio features are raw measurements (not standardized)
   - Facial/posture features are normalized (0-1 range typical)

4. TEMPORAL CONSIDERATIONS
   - No explicit timestamp column (cross-sectional design)
   - Segments may represent different points in the interview
   - Duration varies significantly across segments

================================================================================
SECTION 7: RECOMMENDATIONS FOR PREPROCESSING
================================================================================

1. MISSING VALUE HANDLING
   - Only transcript has missing values (13 rows, 0.65%)
   - Options: Drop rows, impute with empty string, or flag as missing
   - Recommendation: Keep rows, use empty string for transcript

2. FEATURE ENGINEERING OPPORTUNITIES
   - Aggregate segment-level features to user-level (mean, std, min, max)
   - Create ratio features (e.g., speech_rate to duration)
   - Combine emotion features into composite scores
   - Extract sentiment from transcript text

3. MODEL CONSIDERATIONS
   - Tree-based models (RF, XGBoost, LightGBM) are scale-invariant
   - Neural networks may benefit from feature standardization
   - User-level split required (not random row split)
   - Consider multi-task learning for multiple targets

4. FEATURE SELECTION
   - Check for multicollinearity among MFCC features
   - Consider PCA for high-dimensional facial features
   - Remove highly correlated features (>0.95 correlation)

5. OUTLIER TREATMENT
   - Audio features may have extreme values (very fast/slow speech)
   - Consider winsorization or robust scaling for outliers
   - Facial detection ratios < 0.5 may indicate poor quality segments
